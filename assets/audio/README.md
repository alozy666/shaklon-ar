# صوت شكلون

خطة الدرس تنص أن المعلم يسجّل رسائل شكلون بصوته. إلى أن تُضاف التسجيلات تظهر الرسالة نصًا، وينطقها المتصفح آليًا إن كان على الجهاز صوت عربي.

## إضافة تسجيل
1. سجّل الرسالة واحفظها بصيغة mp3 باسم المفتاح، مثل `city_intro.mp3`، في هذا المجلد.
2. أضف المفتاح إلى `manifest.json`:
   ```json
   { "recorded": ["city_intro", "mystery_intro", "district_intro"] }
   ```

## الرسائل الأساسية الثلاث (نصها من خطة الدرس)
| المفتاح | النص |
|---|---|
| `city_intro` | انطفأت مدينتي! أحتاج محققين يكتشفون أشكال أوجه مبانيها لتعود إليها الأنوار. |
| `mystery_intro` | مبنى مختبئ في الضباب! من يعرفه من أوجهه؟ |
| `district_intro` | هذا حيّي الجديد! كل محقق يكتشف أوجه مبانيه وحده، ويرسمها في شهادته. |

بقية المفاتيح ونصوصها في `js/config.js` (الثابت `LINES`)، وتسجيلها اختياري.

لإيقاف النطق الآلي أضف `&tts=0` إلى الرابط.
