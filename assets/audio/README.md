# صوت شكلون

خطة الدرس تنص أن لشكلون صوتًا مسجّلًا. إلى أن تُضاف التسجيلات تظهر الرسالة نصًا، وينطقها المتصفح آليًا إن كان على الجهاز صوت عربي.

## إضافة تسجيل
1. سجّل الرسالة واحفظها بصيغة mp3 باسم المفتاح، مثل `city_intro.mp3`، في هذا المجلد.
2. أضف المفتاح إلى `manifest.json`:
   ```json
   { "recorded": ["city_intro", "mystery_riddle", "city_done"] }
   ```

## الرسائل الأساسية (نصها من خطة الدرس)
| المفتاح | النص |
|---|---|
| `city_intro` | انطفأت أنوار مدينتي! تعود الأنوار إلى كل مبنى عندما تعدّون أوجهه وأحرفه ورؤوسه. |
| `mystery_riddle` | لي 6 أوجه و12 حرفًا و8 رؤوس، لكني لست البيت! من أنا؟ |
| `not_face` | الوجه سطح مستوٍ، وهذا سطح منحنٍ! |
| `not_edge` | الحرف يلتقي فيه وجهان، وهذه حافة منحنية! |
| `city_done` | أضأتم مدينتي، أنتم الآن محققون! |

بقية المفاتيح ونصوصها في `js/config.js` (الثابت `LINES`)، وتسجيلها اختياري.

لإيقاف النطق الآلي أضف `&tts=0` إلى الرابط.
